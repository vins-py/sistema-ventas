# Sistema de Ventas con Python

Este proyecto es un sistema básico de ventas hecho con Python.

Permite registrar productos vendidos, calcular subtotal, IVA y total, guardar tickets en archivos de texto, guardar ventas en un archivo CSV y generar un reporte automático en Excel.

## Funciones principales

- Registrar ventas desde la terminal.
- Calcular subtotal, IVA y total.
- Guardar tickets en la carpeta `tickets`.
- Guardar ventas en `ventas.csv`.
- Generar un reporte en Excel con resumen.
- Agrupar ventas por día.
- Agrupar productos vendidos por día.

## Archivos principales

- `ventas.py`: programa principal para registrar ventas.
- `reporte_excel.py`: genera el reporte automático en Excel.
- `ventas.csv`: archivo donde se guardan las ventas.
- `reporte_ventas.xlsx`: reporte generado con resumen de ventas.
- `tickets/`: carpeta donde se guardan los tickets.

Este proyecto fue creado como práctica de automatización con Python, con enfoque en tareas reales como manejo de archivos, reportes de ventas y generación automática de Excel.
